# 台股自選股追蹤（Chrome 擴充功能）

在瀏覽器上點一下就能看自選台股報價的 Chrome 擴充功能。

> ⚠ 僅供學習與個人用途，請勿用於交易決策或商業應用。

## 功能

- 加入股票代號：4～6 碼，結尾可帶英文字母（例如 `2330`、`00878`、`006208`、`00632R`），上市、上櫃股票和 ETF 都可以查詢
- 顯示股票名稱、現價、昨收、成交量，上漲顯示紅色、下跌顯示綠色、平盤顯示黑色
- 開盤時間（平日 09:00～13:35）開著視窗時每 30 秒自動更新，收盤後和週末不會自動更新
- 按「刷新」可以立即更新，按完後有 10 秒冷卻時間
- 暫時沒有報價時，會顯示上次成功取得的資料，並標示「（快取 時間）」
- 「查看已加入」可以檢視目前追蹤的代號，每檔股票都可以個別刪除
- 顯示最後更新時間

## 安裝

1. 下載本專案的 `v1.0.4.7z`，解壓縮到一個資料夾（可用 [7-Zip](https://www.7-zip.org/) 或 Windows 11 內建的解壓縮）
2. 在 Chrome 網址列輸入 `chrome://extensions/`
3. 開啟右上角的「開發人員模式」
4. 點「載入未封裝項目」，選擇剛剛解壓縮的資料夾（裡面要有 `manifest.json`）
5. 點瀏覽器右上角的拼圖圖示，把「台股自選股追蹤」釘選到工具列

解壓縮的資料夾不能刪除或移動，否則擴充功能會失效。

## 使用

1. 輸入股票代號，按「加入」
2. 報價會顯示在下方清單
3. 按「刪除」可移除單一股票

## 檔案結構

```
v1.0.4.7z
├── manifest.json       擴充功能設定（Manifest V3）
├── popup.html          彈出視窗
├── popup.css           樣式
├── popup.js            畫面與自選股清單
└── service_worker.js   查詢報價
```

## 資料來源

臺灣證券交易所基本市況報導網站的報價 API：
`https://mis.twse.com.tw/stock/api/getStockInfo.jsp`

- 非即時報價，大約會延遲 15～60 秒，僅供參考
- 所有自選股會合併成一次請求查詢（每 20 檔一次），降低被暫時封鎖的機會，請不要把更新頻率調得太高

## 權限

- `storage`：在本機儲存自選股清單和上次的報價
- `https://mis.twse.com.tw/*`：查詢報價

不會收集或傳送任何個人資料。

## 注意事項

- 輸入錯誤的代號會顯示「查無資料」，一樣可以手動刪除
- 國定假日無法判斷，假日在原本的開盤時間開著視窗仍會自動刷新
